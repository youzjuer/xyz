# Project notes

## 股票推荐项目原则

- 先建立推荐框架，再做具体推荐。
- 每个推荐都要包含：标的、逻辑、风险、周期、触发条件、失效条件。
- 避免只给结论；要保留可复盘的依据。
- 区分：稳健观察、进攻型机会、事件驱动、技术面交易。
- 推荐机制使用 `runs/task-001/recommendation-framework-v1.md` 的多层评分框架。
- 若目标是 A股 1个月左右短线弹性，优先使用 `runs/task-007/a-share-sentiment-framework-v2.md`。

## 当前推荐框架

- 股票池过滤：排除 ST、退市风险、低流动性、重大负面、财务异常。
- 基本面质量：ROE、现金流、利润质量、负债、应收账款。
- 估值安全：PE/PB/PS/PEG、历史分位、行业相对估值。
- 景气成长：行业周期、订单、盈利预测、政策方向、产业链位置。
- 价量行为：趋势、平台突破、放量、相对强弱、A股短期反转特征。
- 资金情绪：主力资金、成交额、融资、新闻热度、研报变化。
- 事件催化：政策、展会、财报、订单、并购、回购、价格变化。
- 风险约束：解禁、减持、监管问询、估值拥挤、交易拥挤、事件兑现。

## 待用户确认

- 是否只关注 A 股。
- 是否排除科创板、创业板或只看主板。
- 推荐周期：短线、中线、长线。
- 风险偏好：保守、均衡、激进。
- 是否需要行业限制或排除项。
- 是否允许使用实时网络信息。
