# Project

## Project

- ID: `proj2`
- Name: 股票推荐
- Goal: 建立一个用于生成、记录和复盘股票推荐的项目工作区
- Status: active

## Brief

- 目标是围绕股票推荐形成可复用的分析流程和输出结构。
- 推荐内容应区分事实、判断和假设，避免把不确定信息写成确定结论。
- 每次推荐需要记录依据、风险、适用周期和复盘点。
- 如涉及真实投资决策，应保留风险提示，不把结果包装成保证收益。

## Scope

- 明确推荐目标：短线、中线、长线，或观察名单。
- 建立股票筛选指标和信息来源清单。
- 产出推荐模板，便于后续持续填写和复盘。
- 后续可接入行情数据、财报、新闻、技术面或量化因子。

## Tasks

- `tasks/task-001.md`：定义股票推荐框架与输出模板
- `tasks/task-002.md`：建立第一版候选股票池和筛选指标
- `tasks/task-003.md`：生成首次股票推荐/观察名单

## Notes

- 本项目输出仅作为研究和决策辅助，不构成确定性投资建议。
- 推荐应尽量说明买入逻辑、失效条件、风险点和复盘时间。
