## Diagnosis

The updated discretionary execution rules would have avoided an actual buy if followed strictly, because the stock opened weak and never showed a healthy reclaim pattern.

However, the upstream selection logic was still flawed. It allowed a candidate after a three-day acceleration sequence:

- 2026-05-22: +8.83%
- 2026-05-25: +14.86%
- 2026-05-26: +7.43%

This was not a stable continuation setup. It was a short-term exhaustion setup after consecutive strong days. The previous focused exhaustion filter only caught near-20cm climax bars, but it missed multi-day acceleration exhaustion where the final day is not near limit-up.

Deeper process issue:

301071 was not the mechanical v3 strategy top pick for the 2026-05-26 signal date. The mechanical v3 extended backtest picked 301013 for 2026-05-27 and produced a small 14:30-to-close loss of -0.17%.

301071 came from an untested discretionary overlay: prefer a candidate that looked "less extreme" than raw top-ranked 688362. That overlay had not been encoded and backtested. The failure therefore reveals two separate problems:

- Strategy design problem: raw recent strength can describe either continuation or exhaustion.
- Process problem: untested discretionary substitutions must not be treated as strategy recommendations.

## Failure Category

- Multi-day momentum exhaustion.
- Late-stage chase after consecutive large up days.
- Selection-stage overfitting to short-term strength.
- Execution would have skipped, but recommendation quality was poor.

## Strategy Adjustment

Hypothesis to test:

- Exclude candidates with 3-day return >= 30% and 5-day return >= 35%.
- Exclude candidates when the last 3 trading days are all positive and their total return >= 28%.
- For any candidate with 3-day return >= 25%, require T+1 opening behavior to confirm strength:
  - If T+1 opens below previous close by more than 2.5%, skip.
  - If price does not reclaim previous close or VWAP before 10:30, skip.

This changes the model from chasing raw multi-day strength to requiring evidence that the move has not already exhausted.
