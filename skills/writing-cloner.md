# Skill: writing-cloner

## 目标

分析一组样本文本，提炼可复用的写作画像，用于后续内容创作。

## 输入

- 样本文本：`runs/{{run_id}}/samples/`
- 样本数量：建议 10-30 篇
- 输出目录：`runs/{{run_id}}/voice/`

## 输出

- `voice-profile.md`：写作画像
- `do-dont.md`：应该模仿和避免的写法
- `examples.md`：可复用句式和结构样例

## 流程

1. 统计开头方式、段落长度、常用转折、结尾方式。
2. 提炼观点强度、信息密度、情绪范围、节奏。
3. 识别作者常用结构：故事型、清单型、反常识型、教程型。
4. 输出可执行规则，不写空泛形容词。
5. 给 3 条“像”和 3 条“不像”的判定标准。

## 失败处理

- 样本过少：只输出初版画像，并标记置信度低。
- 样本风格混杂：按风格分组，不强行合并。
- 涉及隐私：移除个人身份信息，只保留写作模式。
