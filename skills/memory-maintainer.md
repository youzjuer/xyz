# Skill: memory-maintainer

## 目标

定期复盘最近任务日志，把真正会复用的信息整理进长期记忆，删除过期或错误内容。

## 输入

- 日志目录：`logs/`
- 运行产物目录：`runs/`
- 当前记忆：`MEMORY.md`、`USER.md`

## 输出

- `runs/{{run_id}}/memory-review/candidates.md`：候选记忆
- `runs/{{run_id}}/memory-review/rejected.md`：拒绝保存的内容及原因
- 更新后的 `MEMORY.md` 或 `USER.md`

## 流程

1. 读取最近 7 天日志和产物摘要。
2. 找出重复出现的偏好、稳定项目背景、复盘结论。
3. 过滤临时任务、代码结构快照、敏感信息和未验证猜测。
4. 将候选记忆按“用户偏好 / 项目背景 / 外部引用 / 工作流”分类。
5. 更新长期记忆前列出变更摘要，重大覆盖需人工确认。

## 失败处理

- 日志不存在：输出“无可维护内容”，不改记忆。
- 发现疑似密钥：停止写入，提示人工处理。
- 记忆冲突：保留现有内容，标记需要确认。
