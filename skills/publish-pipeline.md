# Skill: publish-pipeline

## 目标

把素材和写作画像组合成可发布内容，并把发布前检查、排期和结果记录下来。

## 输入

- 素材摘要：`runs/{{run_id}}/curation/brief.md`
- 写作画像：`runs/{{run_id}}/voice/voice-profile.md`
- 发布目标：Twitter、公众号、博客、邮件或其他渠道
- 输出目录：`runs/{{run_id}}/publish/`

## 输出

- `drafts.md`：候选草稿
- `selected.md`：最终稿
- `schedule.md`：发布时间和渠道
- `result.md`：发布结果或待办

## 流程

1. 基于素材生成多版草稿。
2. 按清晰度、可信度、风格一致性、互动潜力打分。
3. 选出最佳版本，删掉夸张和无证据表述。
4. 生成发布排期，避免一次性集中发布。
5. 发布前要求人工确认；未经确认不对外发送。

## 失败处理

- 素材证据不足：改成“观察/线索”口吻，不写成事实断言。
- 风格冲突：优先保持清晰和准确，不硬模仿。
- 发布失败：记录错误和重试建议，不自动重复轰炸。
